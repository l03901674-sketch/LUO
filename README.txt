LUO — Smart Study demo

Open index.html in a modern browser. The prototype provides local text summarization, sentence-based study prompts, note search, and a simple text-grounded helper.

This is NOT yet a deployed or AI-connected production application. Real AI requires a server-side provider key; PDF upload/processing, account login, cloud sync, internet search, rate limiting, and production security are not included in this prototype.
